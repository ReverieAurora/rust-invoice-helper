# Rust 发票小助手

批量读取一个文件夹第一层中的 PDF 电子发票，提取销售方名称和价税合计，按销售方汇总，并生成适合人和 AI 阅读的 UTF-8 Markdown 报告。

累计价税合计 **大于等于 1000.00 元** 的销售方会被单独列出。报告末尾还会附带一段固定的 AI 分析提示词。

## 简易交互界面

双击项目根目录中的 `invoice-helper.exe`，程序会启动命令行向导：

1. 在菜单中选择统计模式。
2. 通过弹出的 Windows 文件夹选择窗口选择 PDF 发票目录。
3. 查看逐份处理进度和统计结果。
4. 完成后可以在资源管理器中定位生成的报告。

目前提供“销售方累计金额 ≥ 1000 元”模式。交互菜单和处理逻辑已经为后续增加其他模式预留结构。

## 使用方法

### 交互模式

双击 `invoice-helper.exe`，根据终端提示选择模式和 PDF 发票文件夹。

### 命令行

```powershell
.\invoice-helper.exe "D:\发票目录"
```

指定报告位置：

```powershell
.\invoice-helper.exe "D:\发票目录" --output "D:\结果\发票汇总.md"
```

默认报告会保存在所选发票目录中，文件名类似 `发票汇总_2026-09-08_143000.md`。为避免数据丢失，程序不会覆盖已有报告。

## 处理规则

- 只读取所选目录第一层中的 `.pdf` 文件，不递归读取子目录。
- 按文件名排序后逐份处理。
- 金额使用十进制定点数计算，不使用浮点数。
- 只汇总销售方名称和价税合计都可靠提取成功的记录。
- PDF 损坏、加密、没有文字层或字段无法可靠识别时，会记录失败原因并继续处理其他文件。
- 销售方名称必须完全相同才会合并，程序不会擅自合并相似名称。
- 当前版本针对带文字层的电子发票，不包含扫描图片 OCR。

## 从源码构建

需要 Rust stable 工具链：

```powershell
cargo test
cargo build --release
```

生成的程序位于：

```text
target\release\invoice-helper.exe
```
